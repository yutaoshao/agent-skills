# ATS Defect Report

```text
ID: BUG-01
Title: <observable problem and affected area>
Type: defect | requirement ambiguity | UX opportunity | environment blocker | test-data problem
Severity: Blocker | Critical | High | Medium | Low
Priority: P0 | P1 | P2 | P3
Environment: <build, browser, role, data, integration state>
Preconditions: <minimum setup>
Steps:
  1. <step>
  2. <step>
Expected: <behavior required by the source requirement or explicit decision>
Actual: <what happened>
Evidence: <screenshot, response, record, or log reference>
Claim state: Verified | Inferred | Unknown | Decision Needed
Impact: <user, business, data, privacy, or operational consequence>
Reproduction: always | intermittent | not reproduced
Suggested next action: <fix, clarify, collect evidence, or retest>
```

Use the highest severity supported by evidence. Do not inflate severity for
cosmetic preferences or assign a root cause without code or log evidence.
