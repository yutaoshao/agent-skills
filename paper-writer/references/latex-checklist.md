# LaTeX Compilation and Render Checklist

Use the items that apply to the supplied template and target venue.

## Build

- Identify the template's entry point, compiler, bibliography tool, and required auxiliary tools.
- Compile using that path and retain actionable diagnostics.
- Resolve compilation errors, undefined references or citations, duplicate labels, and missing assets before claiming a build is complete.

## Rendered PDF

- Inspect pages containing equations, tables, figures, algorithms, and long references for clipping, overlap, unreadable text, broken floats, and incorrect page breaks.
- Confirm captions, cross-references, labels, notation, and bibliography entries render as intended.
- Check the page limit, anonymization, metadata, and required statements against current venue materials when submitting.

## Report Limits Clearly

Separate a clean local build from submission readiness. A successful compilation does not verify external submission-system fields, current venue policy, or the scientific adequacy of the manuscript.
