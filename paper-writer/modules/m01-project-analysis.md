# Research Artifact Analysis

Use this module to recover a paper-ready account from code, experiment records, notebooks, data, or an existing draft.

Read the smallest set of artifacts that can establish the method, evaluation setting, and reported outcomes. Trace each candidate contribution to implementation, configuration, experiment, or manuscript evidence. Distinguish what the artifacts show from a plausible interpretation.

Deliver a concise evidence map:

| Candidate claim | Supporting artifact | Evidence | Uncertainty or missing evidence |
|---|---|---|---|

Then propose a research story that connects the problem, technical change, and measured result. It is a working framing, not an asserted fact; proceed with the user's supplied framing when it differs.
