# LaTeX Compilation and Render Review

Use this module to build or diagnose a LaTeX paper.

Identify the project entry point and the template's intended build path. Compile with the appropriate engine and bibliography tool, then inspect the log for errors, unresolved references or citations, duplicate labels, missing assets, and material layout warnings. Resolve issues only when the cause is supported by the project source; otherwise report the exact diagnostic.

Inspect the rendered PDF when layout, pagination, floats, tables, equations, figures, or anonymization matter. Preserve the supplied preamble and template conventions unless a requested change requires them. Read [latex-checklist.md](../references/latex-checklist.md) for the relevant completion checks.
