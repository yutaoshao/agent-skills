# 中文论文写作拆解

从成文中提取可观察的表达与组织方式，再转成可迁移的写作步骤。默认中文输出，面向提出方法、模型或系统并以实验验证的理工科论文。

## 工作边界

- 解释原文如何组织信息、建立论证，不声称知道作者的真实构思过程或写作先后。
- 忠实拆解，择优迁移。始终区分 **原文观察** 与 **分析建议**；原文中的套话、跳步和过强结论不自动成为推荐写法。
- 单篇只能支持“该文模式”；多篇中的出现频率也不等于普遍有效性或期刊正式要求。
- 输出指南与写作指令，不在本流程中起草目标论文。指南可供其他 AI 或后续写作任务独立使用，不要求安装其他写作 skill。
- 不把范文的研究对象、方法创新、数值、引用或结论当作目标研究的事实。不编造缺失内容。

## 1. 接收并核对材料

接受 PDF、DOCX、Markdown 或粘贴文本。使用环境已有的文档读取能力；必要时查看原始页面核对阅读顺序、图表和公式，不新增解析程序。

记录每篇的标识、题目、来源文件或链接、可确认的领域与论文类型、材料范围及读取问题。只询问会影响分析的缺失材料；没有目标期刊不妨碍一般拆解。

先核实正文是否可读。扫描件无可用识别能力、双栏顺序混乱、公式或表格不可读时，注明具体页码或位置及影响，继续分析可靠部分，并请求必要的可读材料。区分“原文未设置此节”与“输入未包含或读取失败”。没有可读正文时，只交付材料状态与待补充清单，不生成貌似完成的指南。

## 2. 建立结构与定位

读取 [拆解规范](references/analysis-protocol.md)，依据实际章节建立功能映射。引言可包含相关工作，方法与实验可交叉，讨论可独立；不要重排原文以凑齐六个标题。

按原文顺序为标题、段落、句子、公式和图表建立稳定标识。登记覆盖范围后逐节分析；长文分批保存、维护待处理清单，不能用少数典型段落代替完整拆解。

## 3. 完成逐篇拆解

按 [输出模板](references/output-templates.md) 为每篇生成 `papers/<paper-id>-analysis.md`，包括：

1. 材料状态、章节功能映射和核心论证链。
2. 全部范围内句子的定位、内容概述、表达功能、衔接对象与可迁移写法。
3. 每段的任务、内部推进、上下段关系及必要研究材料。
4. 六类章节的组织模式，以及公式、图表和引用的论证作用。
5. 原文观察、可借鉴模式、适用条件和不宜照搬之处。
6. 覆盖账目与未解决问题。

分析方法与实验时，追踪“研究问题 → 贡献主张 → 方法机制 → 实验问题 → 结果 → 结论”。连接不成立时标明缺口，不替原文补论证。句式提炼必须指出信息槽位及其证据需求，不能只有“先背景、再方法、最后结果”等空泛标签。

## 4. 多篇归纳

仅在有多篇材料时读取并使用输出模板中的比较部分，生成 `comparison.md`。先完成每篇可读范围的拆解，再比较；不完整篇可以参与，但相应章节须标为不可判定。

每条模式给出来源定位、支持篇数、可比较篇数、差异或反例、适用条件，以及是否建议迁移。按论证类型和研究条件分组，不把系统评估、算法对比等不同写法强行平均。跨篇结论遇到不完整材料时报告“可判定样本中 n/m 篇，另有 k 篇不可判定”，不可将未读到算作不存在。

## 5. 生成独立写作指南

只要有足够可读内容可支持写作模式，就生成 `writing-guide.md`；部分材料只生成相应部分的指南并声明覆盖边界。

依照输出模板，把可取模式转成“目标 → 所需材料 → 组织步骤 → 信息槽位 → 句式骨架 → 适用条件 → 检查标准”。指南包含简短来源说明，但理解和执行不能依赖拆解报告、其他 skill 或隐含对话历史。

将研究内容改为语义明确的 `〔占位符〕`。附一段可直接交给 AI 的写作指令，要求基于目标研究材料填写、缺失事实追问或显式占位、按证据强度表达结论。范文展示顺序和建议起草顺序分开表述。

## 6. 验收与交付

- 核对登记的句子与段落是否全部有分析；页眉、页脚、参考文献条目等排除范围单列。未完成项保留明确状态。
- 抽查原文定位、句子衔接、贡献与实验对应关系；全文结论不能依赖未读到的图表或数据。
- 检查单篇模式没有被写成中文论文通则；多篇模式有计数、来源、差异和适用条件。
- 检查指南包含具体可操作步骤，且范文事实没有进入目标研究槽位。只描述一个模式不能算作完整的 AI 写作指令。
- 给出产物链接、完成范围与材料问题。除用户指定位置外，保存到当前任务的 `paper-writing-analysis/`；已有成果保留，新一轮使用独立子目录。
